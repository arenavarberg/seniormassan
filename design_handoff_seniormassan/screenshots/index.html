Seniormässan — Screenshots

A quick visual reference for each page in the design. The HTML prototype is interactive — for hover states, the registration wizard, admin panel, and palette tweaks, open ../Webbplats.html in a browser.

How to capture fresh screenshots: Open ../Webbplats.html in Chrome → open DevTools (Cmd/Ctrl+Shift+I) → press Cmd/Ctrl+Shift+P → type "Capture full size screenshot" → press Enter. Repeat for each page.

01. Visitor / Home page (För besökare)

Hero with image carousel, stats, video, areas, highlights, exhibitor list. Default landing page.

02. Program

Two-stage program columns (Stora Scen + Utställarscenen) with all program points for Wednesday 24 February 2027.

03. Find Us (Hitta hit)

Map placeholder + address, free parking, accessibility info.

04. Contact (Kontakt)

2×2 grid of contact cards: Gästservice, Camilla Bourdette, Vivi Strindö, Susanne Carlsson.

05. Exhibitor info (För utställare)

Hero + Nyhet 2027 callout + full-bleed photo + "Varför ställa ut" + Utställarscen-card + Monterpaket (3 storlekar + förening) + tillägg-info + testimonial with portrait.

06. Registration wizard (modal)

Multi-step booking: Företag → Monter (interactive SVG hall map) → Tillägg (14 products with stock + variants) → Scen (optional time slot) → Granska (review + GDPR). Open by clicking "Boka monter" in the header.

07. Admin panel (demo)

Two tabs: Anmälningar (registrations list + CSV export) and Tillval / lager (stock management). Open via the small "Admin (demo)" button bottom-left.

Tip: live screenshots

The prototype was captured here as static PNGs would require ~1 MB of base64 round-tripping through the design tool — easier to open the file in your browser and take fresh screenshots that match your exact viewport and palette choice. Use the Tweaks panel (look for the "Tweaks" toggle when the design tool is editing the file) to switch between 13 different color palettes before screenshotting.
